# 物權微縮島｜所有權的物權特性

根據上傳教材《公民(所有權的物權特性)(1).pdf》（7 頁，教材頁碼 109–115）製作的高一公民互動教材。

## 功能

- 原生 Canvas 3D 頂點、平面與正交投影：低多邊形微縮島、建築點選、拖曳旋轉鏡頭、縮放及鏡頭目標平移。
- 七大地點：所有權廣場、四特性研究院、電腦交易所、權利救濟所、土地登記所、公共利益公園、創作公民論壇。
- 學生模式：逐關解鎖、每站 2 道題目、即時詳解、反思文字、進度儲存及 JSON 匯出。
- 教師模式：兩節各 50 分鐘教學節奏、教學目標、觀念與解答、全區自由導覽。
- RWD（手機、平板、電腦）、PWA 離線快取、SVG 圖示；不需要登入、API 金鑰、外部套件。

## 使用與部署

1. 將整個資料夾的檔案上傳到 GitHub 儲存庫根目錄。
2. 在 GitHub **Settings → Pages → Build and deployment** 選 **Deploy from a branch**，Branch 選 `main`、Folder 選 `/(root)`。
3. 開啟 GitHub Pages 網址（HTTPS），即可使用與安裝 PWA。注意 `file://` 開啟的檔案不能註冊 Service Worker；本機開發可使用 `python -m http.server 8000` 後瀏覽 `http://localhost:8000/`。
4. 課堂使用時，學生可利用右上角「匯出紀錄」交付 JSON 給教師。

## 注意事項

- 此作品是教材導向的概念學習與形成性評量，不是法律諮詢；真實法律問題應查詢現行法令及個案要件。
- 成績、反思、姓名保存在目前瀏覽器的 localStorage；不會自動同步到雲端。換裝置或清除瀏覽器資料會失去本機紀錄。
- 本版 3D 為**不依賴外部函式庫的自製低多邊形 3D 幾何與正交投影**，可旋轉視角與縮放；未使用 WebGL、物理引擎或 3D 模型匯入，因此不支援第一人稱移動與材質貼圖。
- 部分瀏覽器安裝 PWA 可能需另外準備 192×192 及 512×512 PNG 圖示；目前提供 SVG PWA 圖示。
